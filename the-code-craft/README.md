# THE CODE CRAFT — React starter

A responsive dark-premium portfolio homepage built with React + Vite.

## Requirements
- Node.js 18.18+ (Node 20 LTS recommended)
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## First customizations
1. Open `src/main.jsx`.
2. Replace the sample projects in the `projects` array with your real project names, descriptions, stacks and GitHub/demo URLs.
3. Replace the sample tutorials in the `tutorials` array with your actual lessons and video links.
4. Replace the generic GitHub, YouTube and Instagram URLs in the contact section with your profile URLs.
5. Update the About section with any additional details you want public.

## Brand direction
- Name: THE CODE CRAFT
- Tagline: BUILD. LEARN. CREATE.
- Palette: charcoal black, electric purple and lavender
- Logo concept: geometric code-bracket mark; the current React logo component uses a simple code icon.

## Next phase
Connect the React UI to a Spring Boot REST API and MySQL. Add secure admin authentication and CRUD endpoints for projects and tutorials. Keep credentials and secrets on the backend; do not put database passwords or JWT signing secrets in React.
